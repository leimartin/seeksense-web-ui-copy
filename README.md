# SeekSense - Web UI

### Collaboration

This project was developed in collaboration with Team KaRaVaN.

This repository highlights my specific contribution to the project, including:
* Frontend development using Vue.js (components and UI implementation)
* Implementation of IP whitelisting (system-level access control)
* Password hashing for secure authentication
* Role-Based Access Control (RBAC) implementation
* State management and data handling
* Integration of CRUD operations with backend APIs

> **Note**: The frontend–backend integration was assisted by our full-stack developer.
